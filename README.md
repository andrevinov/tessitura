# Tessitura

> Work in progress.

Tessitura is a deterministic campaign engine for AI-narrated D&D 5.5e campaigns.

It will store campaigns and player characters, resolve actions, rules, dice rolls, and world events, and maintain the canonical world state. The AI narrator will translate player intent into Tessitura commands, select relevant narrative events from its results, confirm what was used, and turn the resolved turn into prose.

The goal is for Tessitura to perform nearly all mechanical and state-management work while returning only the compact, structured context the narrator needs.
