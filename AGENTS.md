# Agent Guidelines

- Keep everything in the repository in English, including code, names, comments, documentation, and tests.
- Use Python and follow Clean Architecture. Keep the domain independent from frameworks, storage, and external interfaces.
- Use Ruff for linting and formatting, Pylance-compatible type annotations, Pytest for tests, and Coverage for test coverage.
- Make focused changes, preserve existing work, and add or update tests for behavior changes.
- Run the relevant checks before considering a change complete.
